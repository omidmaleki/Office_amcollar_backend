# Mobile App Frontend Documentation

## Overview
The `amcollarapp` provides the mobile interface for users, likely optimized for touch interactions and on-the-go management of smart collars.

## Key Features
- **Real-time Tracking**: View pet location on a map.
- **Push Notifications**: Receive alerts for geofencing or health issues.
- **Collar Setup**: Bluetooth/BLE integration for initial device setup.

## Tech Stack
- **Framework**: React Native (implied by `amcollarapp` naming and similar structure).
- **Platform**: iOS and Android.

## Integration
- **API**: Consumes the `Gateway` API.
- **Native Modules**: Access to GPS, Bluetooth, Camera.
